# 🌐 Nexus - IIT JAMMU'S Inter-branch Technical Fest

Welcome to the official repository for **Nexus**, the annual inter-branch technical fest of **IIT Jammu** — a celebration of innovation, technology, and creativity! This website serves as the central hub for all information regarding Nexus, including events, team details, merchandise, and more.

---

## 📌 Overview

**Nexus** brings together students, professionals, and tech enthusiasts from all over the country to explore and showcase cutting-edge technology and revolutionary ideas. This website is built to reflect the spirit of the fest, with modern design, smooth user experience, and detailed information.

---

## 🚀 Features

- ✅ **Responsive Design**: Fully optimized for mobile, tablet, and desktop.
- 🧠 **Interactive Elements**: Engaging animations and dynamic components for enhanced user experience.
- 🎨 **Modern UI**: Clean, intuitive, and visually attractive design.
- ⚡ **Performance Optimized**: Fast-loading and lightweight for seamless browsing.

---

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Deployment**: Hosted on [nexusiitjammu.com](https://nexusiitjammu.com)

---

## 🧪 Running Locally

To run the website locally:

1. **Clone the repository**
   ```bash
   git clone https://github.com/YOUR-USERNAME/nexus-iitjammu.git
   cd nexus-iitjammu


2. Open the `index.html` file in your preferred web browser.
3. To test responsiveness, use browser developer tools (e.g., Chrome DevTools).
